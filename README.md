# 🎮 Jogo da Forca em Python

Um protótipo extremamente simples do clássico **Jogo da Forca**, desenvolvido em Python com o objetivo de praticar conceitos básicos de programação, como estruturas condicionais, laços de repetição, listas e manipulação de strings.

## 📝 Sobre o projeto

O jogo funciona por meio de tentativas de adivinhar uma palavra secreta. O jogador deve digitar letras e descobrir a palavra antes de atingir o limite de erros permitido.

Este projeto foi desenvolvido como exercício de aprendizagem e prática da lógica de programação utilizando Python.

## ⚙️ Funcionalidades

- Sorteio de uma palavra secreta.
- Entrada de letras pelo teclado.
- Exibição das letras já descobertas.
- Contagem de tentativas incorretas.
- Identificação de vitória ou derrota.
